# 하단 내비게이션 아이콘

PNG, WebP 또는 JPEG 아이콘 파일을 이 폴더에 넣고
`lib/app/navigation_icon_assets.dart`의 여섯 경로를 수정하세요.

- 클럽원 관리: `membersOutline`, `membersFilled`
- 팀짜기: `teamsOutline`, `teamsFilled`
- 기록: `historyOutline`, `historyFilled`

outline 경로는 선택되지 않은 상태에, filled 경로는 선택된 상태에 표시됩니다.
권장 크기는 24x24 또는 48x48이며 투명 배경 이미지를 사용하세요.
